Gelöst

So wird gespielt

Setze so viele Kronen, wie das Brett Zeilen hat.

  • Jede Zeile hat genau eine Krone.
  • Jede Spalte hat genau eine Krone.
  • Jede Farbfläche hat genau eine Krone.
  • Zwei Kronen berühren sich nie, auch nicht über Eck.

Einmal tippen setzt ein X für „hier sicher nicht“, zweimal tippen setzt eine Krone, ein drittes Mal leert das Feld. Mit dem Finger über mehrere Felder ziehen setzt X in Serie.

Jedes Rätsel hat genau eine Lösung und lässt sich ohne Raten lösen. Ein Hinweis kostet 15 Sekunden.
